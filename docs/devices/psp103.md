# PSP 103 — surface-potential MOSFET core + JUNCAP200 junctions

Reference: PSP 103.7.0 / JUNCAP 200.6.0 Verilog-A (NXP/CEA-Leti, April
2019), fetched from OpenVAF integration_tests
(`PSP103_macrodefs.include`, `PSP103_module.include`,
`JUNCAP200_macrodefs.include`, `Common103_macrodefs.include`). This is
production source — the same model family behind our failing
`vacask/mul` / hanging `vacask/c6288` fixtures (their `models_psp.inc`).

Scope: DC core (surface potential, mobility, velocity saturation, CLM,
Ids), impact ionization, GIDL, gate-current structure, JUNCAP200, region
flow. Charge/NQS/noise models: structure noted only.

## 1. Mathematical specification

### 1.1 Topology and smoothing primitives

External D, G, S, B. Internal: GP (behind gate resistance), DI/SI
(behind S/D series resistance), BP/BI/BS/BD (substrate resistance
network), NOI (noise correlation), INT1..8 + spline nodes when NQS is
compiled in. Parasitic resistances collapse via
`CollapsableR` ($R \le 0 \Rightarrow$ node short).

Everything is built from two smooth min/max primitives:

$$\mathrm{MINA}(x,y,a) = \tfrac{1}{2}\left(x+y-\sqrt{(x-y)^2+a}\right),\qquad
\mathrm{MAXA}(x,y,a) = \tfrac{1}{2}\left(x+y+\sqrt{(x-y)^2+a}\right)$$

There is **no pnjlim-style iteration limiting in the model**: every
potentially explosive bias is pre-conditioned by a smooth clamp, and the
surface potential is computed by a closed-form analytic approximation
(§1.4) — no internal Newton loop (unlike HICUM's GICCR).

### 1.2 Bias conditioning and S/D symmetry

Source–drain interchange: if $V_{ds} < 0$, swap
($V_{gs} \mathrel{-}= V_{ds}$, $V_{sb} \mathrel{+}= V_{ds}$,
$V_{ds} \to -V_{ds}$, `sigVds = −1`); overlap/GIDL voltages
(`VgsPrime` etc.) are *not* swapped. Smooth $|V_{ds}|$:

$$V_{dsx} = \frac{V_{ds}^2}{\sqrt{V_{ds}^2 + 0.01} + 0.1}$$

Forward-body clamp (keeps $V_{sb}^* > -\phi_x$-ish smoothly):

$$V_{sb}^* = V_{sb} - \mathrm{MINA}\!\left(\mathrm{MINA}(V_{db}, V_{sb}, b_\phi) + \phi_x,\ 0,\ a_\phi\right) + \phi_{x1}$$

with $\phi_x = 0.95\,\phi_B$, $a_\phi = b_\phi = 0.0025\,\phi_B^2$,
$\phi_{x1} = \mathrm{MINA}(\phi_x - \tfrac{1}{2}\sqrt{b_\phi}, 0, a_\phi)$.

Lateral-field (DIBL) shift and subthreshold-slope degradation:

$$V_{dsp} = \frac{2V_{dsx}}{1+\sqrt{1+C_{FD}V_{dsx}}},\quad
\Delta V_g = C_F\,V_{dsp}(1 + C_{FB}V_{sbx}),\quad
V_{sbx} = V_{sb}^* + \tfrac{1}{2}(V_{ds}-V_{dsx})$$

$$\phi_{t1} = \phi_t\,\big(1 + C_T(T)\,dCTG\big)\big(1 + PSCE(1+PSCED\,V_{dsx})(1+PSCEB\,V_{sbx})\big)$$

(interface-states factor $dCTG$ is itself a smooth function of a
clamped surface potential estimate). Normalized gate drive:

$$x_g = \frac{V_{gs} + V_{sb}^* - V_{FB}(T) + \Delta V_g}{\phi_{t1}}$$

### 1.3 Temperature and vertical-doping quantities

$$E_g(T) = 1.179 - 9.025\times10^{-5}T - 3.05\times10^{-7}T^2$$
$$\phi_B = \max\!\left(E_g + \Delta\phi_B + 2\phi_t\ln\!\big(N_{EFF}\cdot\text{phibFac}^{-3/4}\cdot 4\times10^{-26}\big),\ 0.05\right)$$
$$G_0 = \frac{\sqrt{2q N_{EFF}\varepsilon_{si}/\phi_t}}{C_{ox}'}\ \text{(body factor)},\qquad
\text{QM: } \phi_B \mathrel{+}= 0.75\,q_q\,q_{b0}^{2/3},\ \ G_0 \mathrel{*}= 1+\tfrac{4}{3}\tfrac{\Delta\phi_{Bq}}{q_{b0}}$$

Bias-dependent body factor (substrate depletion, DNSUB):
$G_f = G_0\sqrt{1 + D_{NSUB}\,\mathrm{MAXA}(0, V_{gs}+V_{sb}-V_{NSUB}, N_{SLP})}$.
Mobility/velocity/resistance parameters scale as powers of
$T_{ref}/T$: $BETN(T) = BETN\,(T_{ref}/T)^{ST_{BET}}$, similarly MUE,
CS, THESAT, XCOR, RS, and $A2(T)$ for impact ionization; the gain is
$\beta = FACTUO\cdot BETN(T)\cdot C_{ox}'$ (W/L folded in by the scaling
section into `_i` params).

### 1.4 Surface potential — analytic approximation ("the sp calculation")

The implicit normalized Poisson equation solved at source ($x = \psi_s/\phi_{t1}$):

$$(x_g - x)^2 = G_f^2\left[e^{-x} + x - 1 + \Delta_n\left(e^{\,x - x_n} - x - 1\right)\right],
\qquad \Delta_n = e^{-x_n},\ x_n = \frac{\phi_B}{\phi_{t1}} + \frac{V_{sb}^*}{\phi_{t1}}$$

(electron term $\Delta_n$ switched to the rational tail
$k_e/P_3(\cdot)$ beyond the exp clamp). `sp_s` computes $x$ **in closed
form** — no runtime iteration:

1. $|x_g| \le$ margin ($10^{-5}\xi$, $\xi = 1 + G_f/\sqrt2$): series
   expansion $x = \frac{x_g}{\xi}\left(1 + x_g(1-\Delta)G_f\frac{1}{6\sqrt2\,\xi^2}\right)$.
2. Accumulation ($x_g < -$margin): initial guess $\eta$ from a MINA-type
   construction on $y_g = -x_g$, one `sigma` correction
   ($y_0 = \eta + \frac{a\,\nu\,\tau}{\mu_\tau + (\nu/\mu_\tau)\tau^2 c(c^2/3 - a)}$,
   an algebraic Newton-with-log step), then a final Halley-like
   quadratic correction: $x = -(y_0 + 2q_C/(p_C + \sqrt{p_C^2 - 2q_C\,\tau_C}))$
   where $p_C, q_C$ are the residual's first/zeroth derivatives at $y_0$.
3. Inversion ($x_g >$ margin): guess from the depletion solution
   $x_1 = x_g + \tfrac{G_f^2}{2} - G_f\sqrt{x_g + \tfrac{G_f^2}{4} - w}$
   (with a smooth $w$ correction), inversion clamp
   $\eta = \mathrm{MINA}(x_1, x_n+3, 5) - \ldots$, one `sigma2`
   correction to $x_0$, then the same quadratic correction. The
   $\delta_0/\delta_1$ exponentials switch to $k_e/P_3$ rational tails
   near the clamps to keep C³ continuity.

Accuracy is ~nV level; cost ≈ 2–3 exp. The drain side reuses the source
depletion guess (`sp_s_d`, drops the accumulation branch) with
$x_{n,d} = x_{n,s} + V_{dse}/\phi_{t1}$.

For $x_{ds} = x_d - x_s < 10^{-10}$ the difference is recomputed from a
perturbation quadratic (pC/qC form) instead of subtracting — this is
what keeps $g_{ds}$ clean at $V_{ds}\to 0$.

### 1.5 Charge sheet quantities

At a point with surface potential $x$ (source s, drain d, midpoint m):
$E = e^{-x}$, $P = x - 1 + E$, $D = \Delta_n(e^{x-x_n}\text{-terms})$
(inversion-carrier function), with series expansions below
$x < 10^{-5}$. Midpoint:

$$x_m = \tfrac{1}{2}(x_s + x_d),\quad E_m = \sqrt{E_sE_d},\quad
D_m = \tfrac{1}{2}(D_s + D_d) + \tfrac{1}{8}x_{ds}^2\left(E_m - \tfrac{2}{G_f^2}\right)$$

$$x_{gm} = G_f\sqrt{D_m + P_m},\qquad
q_{im} = \phi_{t1}\frac{G_f^2 D_m}{x_{gm} + G_f\sqrt{P_m}},\qquad
q_{bm} = G_f\phi_{t1}\sqrt{P_m}$$

$$\alpha = \eta_p + \frac{G_f(1 - E_m)}{2\sqrt{P_m}},\qquad
q_{im1} = q_{im} + \alpha\,\phi_{t1}$$

($\alpha$ = bulk-charge linearization factor; $\eta_p$ = poly-depletion
factor $1/\sqrt{1+k_p x_{gm}}$ with the full $u_{pd}$ mid-potential shift
when $N_P$ given). $\Delta\psi = dps = x_{ds}\phi_{t1}$.

### 1.6 Mobility, series resistance, Coulomb scattering

$$E_{eff} = E_{eff0}\,(q_{bm} + \eta_\mu q_{im}),\qquad
\mu_{red} = (MUE(T)\,E_{eff})^{THEMU(T)} + CS(T)\left(\frac{P_m}{P_m + D_m}\right)^{THECS(T)/2}$$

Series resistance is folded in as a mobility term (PSP has no internal
d′/s′ for RS by default):

$$G_R = 2\beta R_S(T)\cdot\frac{\rho_b\,q_{im}}{1 + R_{SG}q_{im}},\qquad
\rho_b = 1 + R_{SB}V_{sbx}\ \text{(reciprocal form for negative } R_{SB})$$

$$G_{mob} = (1 + \mu_{red} + G_R)\,R_{xcor},\qquad
R_{xcor} = \frac{1 + 0.2\,X_{COR}(T)V_{sbx}}{1 + X_{COR}(T)V_{sbx}}$$

### 1.7 Vdsat and effective drain bias

From source-side charges ($q_{is}, q_{bs}$, same forms at $x_s$):
$\theta_{sat1} = THESAT(T)\frac{1 + THESATG\,w_{sat}}{G_{mob}}$ (with the
$THESATB$ body factor and the saturating $w_{sat} = 100q/(100+q)$),
$\phi_\infty = q_{is}/\alpha + \phi_{t1}$,
$y_{sat} = \theta_{sat1}\phi_\infty/\sqrt2$ (PMOS: $y_{sat}/\sqrt{1+y_{sat}}$):

$$z_a = \frac{2}{1+\sqrt{1+4y_{sat}}},\qquad
\Phi_0 = \phi_\infty z_a\left[1 + 0.86\frac{z_ay_{sat}(1 - (z_ay_{sat})z_a)}{1 + 4(z_ay_{sat})^2z_a}\right]$$

$$\Phi_2 = 0.98\frac{G_f^2D_s\phi_{t1}}{a_{sat} + \sqrt{a_{sat}^2 - 0.98\,G_f^2D_s}},\quad a_{sat} = x_{gs} + \tfrac{G_f^2}{2},\qquad
\Phi_{sat} = \frac{2\Phi_0\Phi_2}{\Phi_0 + \Phi_2 + \sqrt{(\Phi_0+\Phi_2)^2 - 1.98\cdot2\Phi_0\Phi_2}}$$

$$V_{dsat} = \Phi_{sat} - \phi_{t1}\ln\!\left[1 + \frac{\Phi_{sat}(\Phi_{sat} - 2a_{sat}\phi_{t1})}{G_f^2\,\phi_{t1}^2\,D_s}\right]$$

(subthreshold floor $V_{dsat} = 3.912\,\phi_{t1}$ when $D_s$ underflows).
Effective drain bias — the single smooth linear→saturation knee (AX):

$$\boxed{V_{dse} = V_{ds}\left[1 + \left(\frac{V_{ds}}{V_{dsat}}\right)^{A_X}\right]^{-1/A_X}}$$

### 1.8 CLM, velocity saturation, Ids

$$dL = ALP\cdot\ln\frac{1 + (V_{ds}-\Delta\psi)/V_P}{1 + (V_{dse}-\Delta\psi)/V_P},\qquad G_{\Delta L} = \frac{1}{1 + dL + dL^2}$$

$$dL_1 = dL + ALP1\frac{q_{im}\,s_1}{q_{im1}^2}\cdot q_{im1} + ALP2\,q_{bm}\left(\frac{\phi_{t1}\alpha}{q_{im1}}\right)^2\ln\!\left(1+\frac{V_{dsx}}{V_P}\right),\qquad
F_{\Delta L} = (1 + dL_1 + dL_1^2)\,G_{\Delta L}$$

$$z_{sat} = \theta_{sat1}^2\,\Delta\psi^2\ \left(\text{PMOS: } \tfrac{z_{sat}}{1+\theta_{sat1}\Delta\psi}\right),\qquad
G_{vsat} = \frac{G_{mob}G_{\Delta L}}{2}\left(1 + \sqrt{1 + 2z_{sat}}\right)$$

$$\boxed{I_{ds} = \beta\;F_{\Delta L}\;\frac{q_{im1}\,\Delta\psi}{G_{vsat}}}$$

— the entire drain current: one expression, no region selector beyond
$x_g \le 0 \Rightarrow I_{ds} = 0$. Weak/moderate/strong inversion and
linear/saturation all live inside $q_{im1}$, $\Delta\psi$, $G_{vsat}$.

### 1.9 Impact ionization and GIDL

$$\Delta V_{sat} = V_{ds} - A_3\,\Delta\psi;\qquad
M_{avl} = A_1\,\Delta V_{sat}\exp\!\left(-\frac{A_2(T)\left[1 + A_4(\sqrt{\phi_B + V_{sb}^*} - \sqrt{\phi_B})\right]}{\Delta V_{sat}}\right)$$

$I_{impact} = M_{avl}(I_{ds} + I_{ds,edge})$, stamped DI→BP (unswapped by
sigVds).

GIDL (drain side; GISL mirrored) from the overlap surface potential
$V_{ov}(V_{gd}')$ (own closed-form `sp_ovInit`-seeded solution):

$$V_{tov} = \sqrt{V_{ov}^2 + C_{GIDLD}^2 V_{db}'^2 + 10^{-6}},\qquad
I_{GIDL} = -A_{GIDLD}\,V_{db}'\,V_{ov}\,V_{tov}\,e^{-B_{GIDLD}/V_{tov}}$$

(active only for $V_{ov} < 0$; uses unswapped primed voltages).

### 1.10 Gate current (structure)

Overlap components $I_{gsov}/I_{gdov} = I_{GOV}\cdot T_P\cdot F_s$ with
WKB-style transmission
$T_P = \exp\!\big(B_{OV}(-1.5 + z_g(GC_2 + GC_3 z_g))\big)$,
$z_g = |V_{ov}|/\chi_B$, and smooth carrier-supply factor $F_s$ (MNE/MXE
combinations). Channel component $I_{gc} = I_{GINV}\cdot(\text{same }T_P
\text{ form on }V_{oxm})\cdot$ supply, partitioned into
$I_{gcs}, I_{gcd}$ by a polynomial in the drain fraction; $I_{gb}$
gate–bulk remainder. All stamped between GP and SI/DI/BP with sigVds
unswap.

### 1.11 JUNCAP200 (source/drain junctions)

Per junction, three geometry components — bottom (AB), STI edge (LS),
gate edge (LG) — each with the same five ingredients evaluated at the
smooth-limited junction voltage ($v_j$ from `hypfunction` clamps; the
forward exponential is linearized above $V_{MAX}$, chosen so
$I \le I_{MAX}$):

1. **Ideal**: $I_{id} = I_{sat}\,(e^{V/\phi_{td}} - 1)$ with
   $\phi_{td} = \phi_t\,N_{ID}$, via `idmult`.
2. **SRH**: depletion-width weighted recombination
   $I_{srh} = C_{SRH}\,a_{srh}\,w_{srh}$, $w_{dep} = w_{dep,0}\left(\frac{v_{bi}-v_{j,srh}}{V_{BIR}}\right)^P$,
   $w_{srh}$ a smooth step off $2\psi^*$ (the SRH maximum-recombination point).
3. **TAT** (trap-assisted tunneling): field-enhancement factor
   $\Gamma_{max} = \frac{\sqrt\pi}{2}\frac{a_{tat}}{k_{tat}}\,\mathrm{erfc}(x_{erfc})e^{m_{tat}}$
   on the SRH skeleton — erfc-based closed form.
4. **BBT** (band-to-band): $I_{bbt} = C_{BBT}\,V\,F_{max}^2\,e^{-f_{bbt}/F_{max}}$
   with $F_{max} \propto (V_{BIR} - v_{bbt})/w_{dep}$.
5. **Avalanche/breakdown multiplier**:
   $f_{bd} = \left[1 - (v_{av}/V_{BR})^{P_{BR}}\right]^{-1}$, linearly
   continued past `fstop` to avoid the pole.

$$I_{jun} = I_{FACTOR}\sum_{\text{bot,sti,gat}} (I_{id} + I_{srh} + I_{tat} + I_{bbt})\,f_{bd},\qquad
Q_{jun} = C_{FACTOR}\sum q_{pref}\left[1 - \left(1-\tfrac{v_j}{v_{bi}}\right)^{1-P}\right] + q_{pref2}(V - v_j)$$

(charge = classic depletion power-law below the clamp + linear beyond —
same shape as VBIC's `qj`).

## 2. Flow explanation

Order in the VA module (`evaluateStatic` → `evaluateDynamic`):

1. **Preprocessing** (instance init): geometry scaling → `_i` local
   params; `TempInitialize`/`TempScaling` (§1.3); JUNCAP
   `juncapInitModel` precomputes all per-component constants. All
   x-independent → prep cache.
2. **Bias block**: read node voltages (with DI/SI/GP/BP already behind
   parasitic resistances), compute unswapped primed voltages, S/D
   interchange, $V_{dsx}$, $V_{sb}^*$ conditioning, NUD correction.
3. **`SPCalculation` (DC)**: §1.2 gate drive → $x_s$ (`sp_s`) →
   [if $x_g > 0$]: source charges → $V_{dsat}$ → $V_{dse}$ → $x_d$
   (`sp_s_d`) → midpoint quantities → poly correction → $q_{im}, q_{bm},
   \alpha$ → mobility → CLM → velocity saturation → $H$, $V_{oxm}$ for
   gate current. The $x_g \le 0$ branch short-circuits to $I_{ds}=0$
   with accumulation-side $V_{oxm}$ only.
4. **Current assembly**: $I_{ds} = \beta F_{\Delta L} q_{im1}\Delta\psi/G_{vsat}$;
   overlap SPs → gate currents; GIDL/GISL; edge transistor $I_{ds,edge}$
   (own simplified charge-sheet, §`qi_edge`); impact ionization; .OP
   threshold voltage report.
5. **`SPCalculation` (AC)**: repeated with AC parameter set
   (NEFFAC/CFAC/AXAC/THESATAC, DELVTAC shift) when the CV-separation
   switches are on — charges use this second solve (this is PSP's
   DC/AC split; both are closed-form so cost is ~2×).
6. **Charges**: intrinsic partition (not detailed here), overlap and
   outer-fringe caps, JUNCAP $Q_{jun}$; NQS spline-collocation charges if
   enabled.
7. **Stamp**: currents with `CHNL_TYPE`(±1) and `sigVds` unswap
   (Iimpact/Igcs/Igcd swap targets when reversed); JUNCAP between
   S/D-side junction nodes and BP; parasitic resistor network via
   `CollapsableR`.

State: none beyond charges — the model is fully explicit per iteration
(no internal NR, no history), which is why it batches well.

## 3. Pseudo-code, CPU sequential

```
fn psp103_eval(x, P) -> (I, Q, J, C):        # P = scaled+temp prep
    v = node_voltages(x)                      # GP,DI,SI,BP,... frames
    prim = unswapped(v)                       # VgsP, VsbP, VdbP, VgdP
    (vgs, vds, vsb, sig) = sd_interchange(v)
    vdsx  = vds*vds/(sqrt(vds*vds+0.01)+0.1)
    vsbs  = forward_clamp(vsb, vdb, P)        # MINA chain §1.2

    # --- closed-form SP core (DC) ---
    xg    = (vgs + vsbs - P.vfb_t + delVg(vdsx, vsbx, P)) / phit1(...)
    xs    = sp_s(xg, xn_s(vsbs), P)           # analytic, no iteration
    if xg <= 0: ids = 0; goto leakage
    (qis, qbs, alpha_s) = charges(xs)
    vdsat = vdsat_expr(qis, alpha_s, thesat1(qis), P)      # §1.7
    vdse  = vds*pow(1 + pow(vds/vdsat, P.ax), -1/P.ax)
    xd    = sp_s_d(xg, xn_s + vdse/phit1, P)
    (xm, qim, qbm, alpha, dps) = midpoint(xs, xd, P)       # + poly corr
    gmob  = (1 + mured(qim,qbm,P) + GR(qim,P)) * rxcor(P)
    (fdl, gdl) = clm(vds, vdse, dps, qim, qbm, alpha, P)
    gvsat = 0.5*gmob*gdl*(1 + sqrt(1 + 2*zsat(dps, thesat1)))
    ids   = P.bet * fdl * (qim + alpha*phit1) * dps / gvsat

leakage:
    iimp  = mavl(vds, dps, vsbs, P) * (ids + ids_edge(...))
    (igsov, igdov, igcs, igcd, igb) = gate_currents(prim, Voxm, P)
    (igidl, igisl) = gidl(prim, overlap_sp(prim, P), P)

    # --- JUNCAP200 per junction (source, drain) ---
    for j in (Vsb_jct, Vdb_jct):
        vj = hyp_clamps(j, P)
        ij[j] = P.ifactor * sum(id+isrh+itat+ibbt over bot/sti/gat) * fbd(j)
        qj[j] = P.cfactor * depletion_q(vj) ...

    # --- AC SP pass for charges if SW* on, else reuse DC ---
    q_intrinsic = charge_partition(spcalc_ac_or_dc(...))

    return stamps(sig, CHNL_TYPE, ids, iimp, ig*, igidl, ij, q...)
```

Our AD scalar type differentiates the whole chain; all branches
(`xg<=0`, `x<1e-5` series switches, `Ds>ke05`) select on values, so each
iteration is one smooth composition — same pattern as the rest of
`modules/devices/src/`.

## 4. Pseudo-code, GPU parallel (batched SoA)

PSP is the best large model for SIMT in this doc set: fully explicit
(no inner Newton, unlike HICUM), one region branch ($x_g$ sign), and
every guard already written as a smooth function by the model authors.

```
kernel psp103_batch(g, desc, blob, x, env):
    # batch key: (model, node-config: rgate/rbulk/rs collapse set, NQS off)
    for i = g.tid; i < desc.count; i += g.stride:
        v = gather(x, gath[i*NU..])
        p = prep[i]                          # scaled _i + temp + juncap consts

        sig  = sign1(vds(v))                 # swap as signed frame, unswap at
                                             # scatter (Iimpact/Igc* row select)
        xs   = sp_s(xg, xn, p)               # 3-way branch on xg sign:
                                             # register-only divergence, both
                                             # heavy paths ~= 2 exp each; or
                                             # evaluate inversion+accumulation
                                             # and select (2x flops, 0 div)
        core = charges->vdsat->vdse->sp_d->midpoint->mobility->clm->vsat
        ids  = p.bet * core.fdl * core.qim1 * core.dps / core.gvsat
        aux  = iimp + gate_currents + gidl   # straight-line, select()-guarded
        jun  = juncap(v.jct_s, p) , juncap(v.jct_d, p)   # branchless-able:
                                             # each component gated by its
                                             # C-parameter (model-uniform)

        scatter_add(g.rhs, gath, kcl(sig, ids, aux, jun) + env.alpha*q + hist)
        if WITH_DIAG: scatter_add(g.diag, ...)
```

Notes: (a) the JUNCAP component enables (CSRH/CTAT/CBBT = 0 skips) are
model parameters → warp-uniform branches, keep them real; (b) the
`sp_s` accumulation-vs-inversion split is the only data-dependent
divergence — for mixed-logic batches (c6288!) predicating both paths
costs ~2 exp per lane and removes it entirely; (c) the AC second SP
pass doubles core flops only when SWDELVTAC/SWQSAT are set — bake the
switch into the batch key.

## Noise model (in-device)

Contract: [noise-contract.md](noise-contract.md). PSP103 noise is
**in the VA** (source-verified fragments, PSP103_module.include
~1697-1841 and macrodefs `TempScaling`):

- Prefactors: $n_t = FNT\cdot 4kT$ (channel thermal, FNT default 1);
  $S_{fl,pre} = \phi_t^2\,\beta/(C_{ox}/q)$.
- Channel thermal: $S_{id} = n_t\cdot(\text{charge-based } g_{ideal}
  \text{ from } q_{im}\ldots)$, emitted as
  `white_noise(MULT*sqid^2*(1 - c_igid^2))` on DI-SI **plus** the
  correlated part routed through the NOI node network with
  `white_noise(nt/mig)` -- i.e. induced gate noise with correlation
  coefficient $c_{igid}$ built in (SWIGN switch).
- Flicker: `flicker_noise(MULT*Sfl, EF)` with
  $S_{fl} = S_{fl,pre}\,I_{ds}\,G_{vsat}^{-1}\left[(NFA - NFB N_1 + NFC N_1^2)\ln\frac{N_m + \Delta/2}{N_m - \Delta/2} + (NFB + NFC(N_m - 2N_1))\Delta\right]/N_1$
  (carrier-density form, verified lines 1716-1718; edge transistor has
  its own parallel set).
- Parasitic resistances: thermal via the `CollapsableR` macro
  (`white_noise` per collapsible R, verified macrodefs:271).
- Gate/GIDL currents: shot contributions in the VA.

This is the model whose noise the target hook can adopt verbatim: the
VA contribution list IS `noisePsd` (one white + one flicker + one
correlated pair per region). Our `psp.zig` port must mirror it rather
than declare `noise_gens` approximations.
