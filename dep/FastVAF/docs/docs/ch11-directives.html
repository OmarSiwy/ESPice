Chapter 11: Compiler Directives

Compiler directives control the behavior of the compiler through the source text. All compiler directives are prefixed with the grave accent character (`). A compiler directive takes effect from the point where it appears in the source text until another directive overrides it, or until the end of all source files, unless it is a point directive (such as `include).

Compiler directives are not scoped by modules or other design elements. They apply globally from the point of occurrence through all subsequent source text in compilation order.

11.1 `define and `undef

11.1.1 `define

The `define directive creates a text macro. Once defined, the macro name can be used anywhere in the source text and shall be replaced by the macro text.

compiler_directive ::=
    `define text_macro_definition

text_macro_definition ::=
    text_macro_name macro_text

text_macro_name ::=
    text_macro_identifier [ ( list_of_formal_arguments ) ]

list_of_formal_arguments ::=
    formal_argument_identifier { , formal_argument_identifier }

text_macro_identifier ::=
    identifier

The macro text starts after the first whitespace following the macro name (or the closing parenthesis for macros with arguments) and continues to the end of the line. A backslash (\) at the end of a line indicates that the macro text continues on the next line.

`define SIZE 8
`define BYTE_RANGE [`SIZE-1:0]

Multi-line Macros

A macro definition may span multiple lines by escaping the newline with a backslash (\). The backslash-newline pair is replaced by nothing (the lines are concatenated).

`define RESISTOR(name, p, n, r) \
    analog begin \
        I(p, n) <+ V(p, n) / r; \
    end

Macros with Arguments

A text macro may be defined with formal arguments. The number of formal arguments and actual arguments shall be the same. Actual arguments are substituted for formal arguments during macro expansion.

text_macro_usage ::=
    `text_macro_identifier [ ( list_of_actual_arguments ) ]

list_of_actual_arguments ::=
    actual_argument { , actual_argument }

actual_argument ::=
    expression
`define MAX(a, b) ((a) > (b) ? (a) : (b))
`define CLAMP(val, lo, hi) `MAX(lo, ((val) < (hi) ? (val) : (hi)))

y = `MAX(x, threshold);

The left parenthesis of the formal argument list shall follow the macro name with no intervening whitespace. If whitespace separates the macro name from a left parenthesis, the parenthesis is treated as part of the macro text, not as a formal argument list.

A text macro name can be used to represent any part of the source description, but a macro definition shall not split a lexical token across the boundary of the definition. Once defined, a text macro can be used anywhere in the source text, including in other macro definitions.

Predefined Macros

MacroDescription
`__LINE__Integer: current source line number.
`__FILE__String: current source file name.

11.1.2 `undef

The `undef directive undefines a previously defined text macro. After `undef, the macro name is no longer recognized as a macro and any attempt to use it shall be treated as an error (unless it is subsequently redefined).

compiler_directive ::=
    `undef text_macro_identifier
`define VERBOSE
// ... code using `VERBOSE ...
`undef VERBOSE

It is not an error to `undef a macro that has not been defined.

11.2 Conditional Compilation: `ifdef, `ifndef, `else, `elsif, `endif

Conditional compilation directives control which portions of source text are compiled. The source text within a false branch is not compiled and has no effect on the simulation.

ifdef_directive ::=
    `ifdef text_macro_identifier
        ifdef_group_of_lines
    { `elsif text_macro_identifier
        elsif_group_of_lines }
    [ `else
        else_group_of_lines ]
    `endif

ifndef_directive ::=
    `ifndef text_macro_identifier
        ifdef_group_of_lines
    { `elsif text_macro_identifier
        elsif_group_of_lines }
    [ `else
        else_group_of_lines ]
    `endif

`ifdef tests whether a macro has been defined (by `define and not subsequently `undef'd). `ifndef tests whether a macro has not been defined. The branches are mutually exclusive.

`ifdef DETAILED_MODEL
    // Detailed model equations
    I(p, n) <+ is * (limexp(V(p, n) / ($vt * n)) - 1.0);
`elsif SIMPLE_MODEL
    // Simplified model
    I(p, n) <+ V(p, n) / R;
`else
    // Default model
    I(p, n) <+ gm * V(p, n);
`endif

Conditional compilation directives may be nested. Each `ifdef or `ifndef shall be matched with a corresponding `endif. An `elsif or `else always belongs to the nearest preceding unmatched `ifdef or `ifndef.

`ifndef OVERRIDE_TEMP
    `define TEMP 300.15
`endif

`ifdef HIGH_VOLTAGE
    `ifdef THERMAL
        // High-voltage thermal model
    `else
        // High-voltage isothermal model
    `endif
`else
    // Standard model
`endif

11.3 `include

The `include directive inserts the entire contents of another source file at the point of the directive. The included file is processed as if its contents replaced the `include directive.

include_directive ::=
    `include "filename"

The filename is specified as a string enclosed in double quotes. The mechanism for locating the file is implementation-defined, but typically includes searching the current directory and any directories specified by tool-specific options.

`include "disciplines.vams"
`include "constants.vams"

module resistor(p, n);
    inout p, n;
    electrical p, n;
    parameter real r = 1.0;
    analog
        I(p, n) <+ V(p, n) / r;
endmodule

`include directives may be nested: an included file may itself contain `include directives. Recursive inclusion (a file including itself, directly or indirectly) results in undefined behavior.

The files disciplines.vams and constants.vams are standard include files defined by the Verilog-AMS LRM. disciplines.vams defines commonly used natures and disciplines. constants.vams defines physical and mathematical constants as macros.

11.4 `resetall

The `resetall directive resets all compiler directives to their default values. It causes all compiler directives, including text macros and the default discipline, to be reset.

resetall_directive ::=
    `resetall
`resetall

module mymod(p, n);
    // All directives now at defaults
endmodule

The `resetall directive shall be specified outside any design element (module, nature, discipline, etc.). It is recommended to place `resetall at the beginning of each source file so that the compilation of each file is independent of the compilation order and other source files.

11.5 `default_discipline

The `default_discipline directive sets the default discipline for all undeclared nets in modules that follow the directive.

default_discipline_directive ::=
    `default_discipline discipline_identifier

When a net is implicitly declared (by appearing in a port list or connection without an explicit type declaration), the discipline assigned to that net is determined by `default_discipline. If no `default_discipline is in effect, the default net type (from `default_nettype or the default wire) is used for implicit net declarations.

`include "disciplines.vams"
`default_discipline electrical

module resistor(p, n);
    inout p, n;
    // p and n are implicitly 'electrical' discipline
    parameter real r = 1.0;
    analog
        I(p, n) <+ V(p, n) / r;
endmodule

The scope of `default_discipline extends from the point of the directive until another `default_discipline directive, a `resetall directive, or the end of all source text.

11.6 `default_transition

The `default_transition directive sets a default transition time for analog signals. When specified, analog operators that produce discontinuous output (such as direct contribution statements that change abruptly) shall apply a transition with the specified time.

default_transition_directive ::=
    `default_transition transition_time

The transition_time shall be a non-negative real number specifying the default transition time in seconds.

`default_transition 10n

module dac_1bit(out, in);
    output out;
    input in;
    electrical out, in;
    parameter real vhi = 1.0;
    parameter real vlo = 0.0;
    analog begin
        // The transition filter will use 10ns as default rise/fall time
        V(out) <+ transition(V(in) > 0.5 ? vhi : vlo);
    end
endmodule

If a transition filter call explicitly specifies its own transition times, those explicit values override the default. If no `default_transition is in effect and no transition time is specified in the filter call, the transition time is 0 (i.e., an ideal step).

The scope of `default_transition extends from the point of the directive until another `default_transition directive, a `resetall directive, or the end of all source text.

11.7 `default_nettype

The `default_nettype directive specifies the net type for implicitly declared nets.

default_nettype_directive ::=
    `default_nettype net_type_or_none

net_type_or_none ::=
    wire | tri | tri0 | tri1 | wand | triand | wor | trior | trireg | none

When `default_nettype none is specified, all nets must be explicitly declared. Any implicit net declaration is an error.

`default_nettype none

The default net type before any `default_nettype directive is wire. The scope of this directive extends until another `default_nettype directive, a `resetall directive, or the end of all source text.

11.8 `begin_keywords and `end_keywords

The `begin_keywords directive specifies which set of keywords to recognize. This provides a mechanism for backward compatibility and forward compatibility of source files.

begin_keywords_directive ::=
    `begin_keywords "version_specifier"

end_keywords_directive ::=
    `end_keywords

The version_specifier is a string that identifies the set of keywords. Valid version specifiers include:

Version SpecifierDescription
"1364-1995"Verilog IEEE Std 1364-1995 keywords
"1364-2001"Verilog IEEE Std 1364-2001 keywords
"1364-2001-noconfig"Verilog IEEE Std 1364-2001 keywords without configuration keywords
"1364-2005"Verilog IEEE Std 1364-2005 keywords
"VAMS-2.4"Verilog-AMS LRM 2.4 keywords
`begin_keywords "1364-2005"

module mymod(input wire a, output wire b);
    // Uses 1364-2005 keyword set
endmodule

`end_keywords

The `begin_keywords / `end_keywords directives shall be paired and shall not be nested. They shall appear outside any design element. Words that are keywords in the specified version set are reserved; words that are not keywords in that set are available as identifiers.

11.9 `timescale

The `timescale directive specifies the time unit and time precision for the modules that follow it.

timescale_directive ::=
    `timescale time_unit / time_precision

time_unit ::=
    magnitude unit

time_precision ::=
    magnitude unit

magnitude ::=
    1 | 10 | 100

unit ::=
    s | ms | us | ns | ps | fs

The time_unit specifies the unit of measurement for time values and delays. The time_precision specifies the precision to which time values are rounded. The time precision shall be at least as precise as the time unit (i.e., the precision value shall be less than or equal to the unit value).

`timescale 1ns / 1ps
UnitValue
s1 second
ms10-3 seconds
us10-6 seconds
ns10-9 seconds
ps10-12 seconds
fs10-15 seconds

In Verilog-A, the `timescale directive primarily affects the interpretation of delay values and the $realtime system function. Analog modules typically use SI units for time via access functions and analysis functions, independent of `timescale.

11.10 `pragma

The `pragma directive passes implementation-specific information to the compiler. Pragmas that are not recognized by a compiler shall be ignored.

pragma_directive ::=
    `pragma pragma_name [ pragma_expression { , pragma_expression } ]

pragma_expression ::=
    pragma_value
    | pragma_name = pragma_value

pragma_value ::=
    ( pragma_expression { , pragma_expression } )
    | number
    | string_literal
    | identifier
`pragma protect begin_protected
`pragma protect end_protected
`pragma reset

The interpretation of pragmas is entirely implementation-defined. A compiler that does not understand a particular pragma shall ignore it without issuing an error.

11.11 `line

The `line directive specifies the original source file line number and file name, used by preprocessors and code generators to maintain traceability back to the original source.

line_directive ::=
    `line number "filename" level

The number is the line number for the next line. The filename is the source file name. The level is 0, 1, or 2: 0 indicates neither entering nor leaving an included file; 1 indicates entering an included file; 2 indicates leaving an included file.

`line 55 "originalfile.va" 0

11.12 `unconnected_drive and `nounconnected_drive

The `unconnected_drive directive specifies the default value for unconnected input ports.

unconnected_drive_directive ::=
    `unconnected_drive pull1
    | `unconnected_drive pull0

nounconnected_drive_directive ::=
    `nounconnected_drive

`unconnected_drive pull1 causes unconnected input ports to be pulled up. `unconnected_drive pull0 causes unconnected input ports to be pulled down. `nounconnected_drive cancels the effect of `unconnected_drive.

These directives primarily apply to digital net types. In pure Verilog-A analog modules, unconnected ports behave according to the discipline's default (e.g., floating nodes in the electrical discipline).

11.13 `celldefine and `endcelldefine

The `celldefine directive tags module definitions as cell modules. Cell modules may receive special treatment from certain tools (e.g., for delay calculation or timing analysis).

celldefine_directive ::=
    `celldefine

endcelldefine_directive ::=
    `endcelldefine
`celldefine
module AND2(out, a, b);
    output out;
    input a, b;
    // ...
endmodule
`endcelldefine

The `celldefine and `endcelldefine directives shall bracket module definitions. They shall appear outside module definitions.
